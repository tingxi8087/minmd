# MinMD

可自行部署的轻量文档空间，支持文档编辑、表格编辑，以及 PPTX、PDF、视频、图片只读预览。前台参考飞书交互，管理后台和后端复用 MAS。

前台位于 `apps/web`，后端和管理后台复用 MAS。账号、空间与成员、文件树、收藏和回收站使用服务端数据；文档采用文件权限鉴权的 Yjs 协作，表格采用 FortuneSheet 与服务端权威引擎，两者支持持久化确认、版本历史及恢复。图片和 PPTX 原文件使用私有附件存储。访客分享、空间 AI、API / MCP 与演示导入已接入业务接口；单实例 Docker 部署和独立环境备份恢复已验证。

设计见 [TRD](docs/TRD.md)，进度见 [TODO](TODO.md)，脚手架版本和许可证见 [上游来源](docs/UPSTREAM.md)。开发规范见 [AGENTS.md](AGENTS.md)。

## 启动

要求 Bun 1.3.13+、PostgreSQL（已用 PostgreSQL 18 验证）。从仓库根目录执行：

```sh
bun install --frozen-lockfile
cp .env.example .env
```

已有 `.env` 时不要覆盖；旧配置需将 `AUTH_TRANSPORT` 设为 `cookie`，并将 `PUBLIC_ORIGIN` 和 `APP_PUBLIC_ORIGIN` 统一设为后端访问来源（默认 `http://127.0.0.1:9811`），并在启动前执行下面的迁移。填写数据库连接和首次管理员账号密码，数据库需预先创建；迁移只创建表结构。

```sh
bun run db:migrate
bun run dev
```

当前迁移基线为 `database/migrations/0000_initial.sql`，直接创建完整结构，`meta` 保存对应快照。基线沿用旧链最后一次迁移 `0013_safe_starfox` 的时间标记；已执行完旧链的数据库再次运行 `bun run db:migrate` 会跳过初始化，保留现有内容及迁移记录。尚未执行完旧链的数据库须先用原版本补齐旧迁移；新数据库直接运行当前迁移。后续结构变更继续生成增量迁移，不重复合并或更改基线时间。

统一开发入口：前台 <http://127.0.0.1:9811/>，后台 <http://127.0.0.1:9811/admin/>，接口也使用同一来源。后端仅在 `APP_ENV=development` 且 `WEB_DEV_PROXY=true` 时反代本机两个 Vite 服务；无需构建，关闭 HMR 后修改前端代码刷新页面即可。`GET /api/health` 会实际检查数据库连接。端口由 `.env` 的 `WEB_PORT`、`WEB_CMS_PORT`、`PORT` 配置，后端变更时同步修改 `API_PROXY_TARGET`。

前后台使用独立 Cookie 身份和 CSRF 校验，配置模板默认 `AUTH_TRANSPORT=cookie`。前台注册默认关闭，可由后台创建前台账号；开发前台来源由 `APP_PUBLIC_ORIGIN` 和 `APP_DEV_ORIGINS` 配置。

前台用户密码长度为 6–128 位，注册、后台创建 / 重置及用户自行修改使用同一限制。

没有前台账号且未完成初始化时，首次进入前台会显示两步向导：创建账号、设置空间名称和选填描述。提交会在同一事务中创建账号、所有者空间、可编辑的「欢迎使用 minmd」引导文档及登录会话，完成后直接打开文档；初始化不依赖公开注册开关。并发提交只允许一个初始化成功，完成标记不会随账号删除而清除。升级已有前台账号的数据库会自动标记已初始化。

后台新建前台用户默认勾选「创建默认空间」，可取消；勾选后同时创建「昵称的空间」（没有昵称则使用账号）和引导文档。编辑已有用户不提供此选项。管理接口的 `createDefaultSpace` 仅在新建时接受，省略时不创建空间，兼容已有调用方。

后台前台用户表单支持头像上传、预览、更换和移除，允许 1MB 以内的 PNG、JPEG、WebP、GIF；保存用户资料后生效。头像为公开图片，存放于私有附件目录下的 `avatars` 子目录，备份时随附件目录保留。额外 JSON 资料和前台角色能力仍由接口保留，当前用户表单不展示；编辑用户不会清空已有资料或角色分配。

可选开发数据库（需要 Docker 正常运行）：

```sh
docker compose -f deploy/compose.yaml up -d
```

此 Compose 只启动开发 PostgreSQL，默认连接与 `.env.example` 一致。完整应用使用独立 [生产 Compose](deploy/compose.production.yaml)，步骤及单实例边界见 [部署与备份恢复](deploy/README.md)。首次管理员从 `.env` 初始化，仅在库中没有超管时生效。不要对外使用模板默认密码。

## 命令和目录

| 命令 | 用途 |
|---|---|
| `bun run dev` | 同时启动前台、后台、后端；一个子服务退出时关闭其他子服务 |
| `bun run dev:web` | 单独启动前台 |
| `bun run dev:web-cms` | 单独启动管理后台 |
| `bun run dev:server` | 单独启动后端 |
| `bun run build` | 构建 `dist/web`、`dist/web-cms`、`dist/server` |
| `bun run start` | 运行构建后的后端；预发 / 正式可挂载后台，前台需单独静态服务 |
| `bun run preview` | 预览构建后的前台（仅静态页面，不代理业务 API） |
| `bun run typecheck` | 检查后端和两个前端 |
| `bun run check` | 类型检查、后端测试和现有前台行为检查；未指定测试库时数据库测试跳过 |
| `bun run test:integration` | 使用 `TEST_DATABASE_URL` 指定的专用测试库运行数据库 / 鉴权测试 |
| `bun run db:generate` / `bun run db:migrate` | 生成 / 执行数据库迁移 |

```text
apps/web/              MinMD 前台及编辑器
apps/web-cms/          MAS 管理后台
apps/app_server/       MinMD 业务后端及前台账号模块
system/server/         通用认证、角色权限、日志和基础服务
config/                权限及开发配置
database/migrations/  数据库迁移
scripts/               根目录开发、构建与数据库工具
apps/web/scripts/      原有前台行为检查脚本
deploy/                开发 / 生产 Compose、Dockerfile、代理及备份恢复
```

根目录维护唯一 `bun.lock`，各应用通过 Bun workspace 安装。前台接口使用 `/api`；开发前后台由后端统一反代，内部 Vite 端口不作为浏览器入口。后台部署路径示例为 `/admin`，修改配置后需重启后端。正式 Cookie 模式需要 HTTPS 和匹配的访问来源。

验收命令示例：

```sh
bun run check
RUNTIME_PROCESS_TEST=true bun test tests/runtime-process.test.ts
DEV_PROCESS_DATABASE_URL=postgresql://user:password@127.0.0.1:5432/minmd_test RUNTIME_PROCESS_TEST=true bun test tests/dev-process.test.ts
bun run --cwd apps/web-cms lint
TEST_DATABASE_URL=postgresql://user:password@127.0.0.1:5432/minmd_test bun run test:integration
```

数据库测试必须使用独立 `_test` 库，不指向日常开发库或生产库。配置、运行日志、数据库文件、上传文件和验收截图均不提交 Git。`dist/.env.example` 仅为公开配置模板，不包含本机凭证。

本机设置了全局 HTTP 代理时，验收命令需在前面加 `env -u HTTPS_PROXY -u HTTP_PROXY -u ALL_PROXY`，确保本地健康检查直接连接。开发进程已对后端和 Vite 的本地代理设置 `NO_PROXY`。

## 已有交互

- 浏览器标签页使用「当前内容 · minmd」动态标题：文件名跟随授权后的读取及重命名更新，文档标题输入同步；列表和设置页面显示当前空间，文件夹显示目录名。登录、首次初始化、通知、分享和访问受限状态使用对应标题，切换路由或账号时不沿用旧文件名。

- 空间切换、文件夹浏览、类型筛选、搜索、列表 / 网格视图。
- 新建、重命名、收藏、移动、回收站删除 / 恢复；文件列表、网格和左侧文件树支持自定义右键菜单，「…」使用相同菜单。
- 文档「…」菜单支持移动、导入 / 导出与详情（收藏和分享使用顶栏入口）；修改正文标题即重命名，左侧文件菜单保留重命名入口。正文右键支持撤销 / 重做、复制 / 剪切、粘贴纯文本、全选、分享与导出，表格使用专用菜单。
- 移动端文档顶栏将版本历史、收藏和主题设置收进「…」，分享使用图标按钮；保存状态仍保留在顶栏，桌面端继续显示独立操作入口。
- 移动端编辑工具栏保持一行，保留撤销、重做、正文/标题、粗体、斜体和下划线；字号、颜色、链接、列表、插入及表格行列操作放入带文字说明的「更多编辑功能」面板。
- 移动端表格合并功能 Tab，工具栏优先显示撤销、重做、常用文字格式和筛选，其余功能使用编辑器的「更多」面板；顶栏的版本、导入、导出和主题设置收进「…」。移动端 PPT 默认隐藏缩略图，底部保留翻页和全屏，上传、下载、缩放及缩略图开关放在顶栏「…」中。
- FortuneSheet 容器尺寸与工具栏宽度缓存补丁放在 `patches/`，由根目录 `patchedDependencies` 配置，Bun 安装时自动应用。画布和工具栏跟随实际容器尺寸变化，切换功能 Tab 时按当前工具集重新计算溢出位置并关闭旧面板，编辑器无需重建。
- 侧栏文件树支持嵌套文件夹、父子文档、拖拽移动与同级排序；拖到文件夹主体松开即移入并展开目标，上下边缘用于排序。节点菜单支持在当前位置新建。移动会阻止循环嵌套与跨空间移动。
- 移动 / 恢复弹窗使用目录树与完整路径搜索选择目标；移动时当前位置不可提交，自身及子目录不可选，文档可选择父文档，表格、幻灯片和文件夹仅选择文件夹。
- 导航可展开 / 收起，拖动右侧边缘可调整宽度（180–400px），布局偏好本地保存；底部保留 AI、回收站、设置三个图标，成员管理在设置中。
- 文档标题按 Enter 进入正文，中文输入法确认文字时保持标题焦点。
- 文档支持标题、正文、文本格式、列表、待办、引用、代码、链接、图片和正文表格；选中文字浮动菜单、`/` 插入菜单、目录跳转、撤销 / 重做。
- 可从 `/` 菜单插入 Mermaid 图表，或将代码块语言设为 `mermaid`。Mermaid 代码块默认显示图表，预览画布最高 360px（窄屏 280px），支持加减缩放、拖动及全屏弹层查看，全屏画布内支持 Mac 触控板捏合并以手势位置为中心缩放（兼容 Safari 手势），滚轮按纵横轴移动，支持 Shift＋滚轮横移，键盘 `＋` / `＝` / `－` 和数字键盘加减键可缩放（无需 Command / Ctrl）；滚轮在预览区域继续滚动文档。代码块标题栏提供删除按钮，可撤销，只读时隐藏。可在「图表 / 源码」间切换；视图状态仅属于当前页面，不写入文档或影响其他协作者。编辑后防抖绘制，语法错误保留源码。历史版本及分享页使用相同只读渲染，Markdown 导入导出保留 Mermaid 围栏；渲染库按需加载，支持深浅主题，图表不启用 HTML、点击链接或外部图片。单图最多 50000 字符、500 条边。
- 代码块内选中文字不显示浮动格式栏；语言下拉支持常用类型与自定义类型（搜索后选择自定义项），语言随文档保存，并保留在 Markdown 导入 / 导出的代码围栏中；lowlight 语法高亮随编辑和语言切换实时更新，支持浅色 / 深色主题，未知类型保持纯文本。
- 插入表情支持分类、搜索与最近使用；高亮块可调整表情和主题底色，折叠块支持标题与正文编辑、展开 / 收起；文档引用可搜索当前空间并跳转，日期可选择后插入。
- `/` 菜单支持分组、中文 / 常用拼音缩写 / 英文搜索；正文空格后的行内菜单提供表情、日期与文档引用。菜单自动避让光标行，打开时锁定文档滚动。
- 高亮块导出 Markdown 转成引用，折叠块展开为标题及全部正文，文档引用转成链接；导出前提示外观变化，原文保留。
- H1–H6 支持章节折叠：标题 hover 显示箭头，收起到下一个同级或更高级标题；嵌套折叠状态及刷新保留，目录跳转自动展开必要的父级，Markdown 始终导出完整内容。
- 正文表格 hover / 聚焦时显示底部与右侧「＋」，可直接在末尾追加行列；选中单元格后工具栏提供上下插行、左右插列，右键菜单提供插入与删除行列、删除范围高亮，支持选中多行 / 多列批量删除；删除整个表格在工具栏，操作可撤销，保留列宽拖拽。
- 文档图片单击显示选中边框与四角缩放手柄，工具栏支持左对齐、居中、右对齐；按比例拖动调整大小、支持撤销 / 重做和恢复原始大小。双击或点击放大按钮打开预览，支持缩放与拖动查看。尺寸和对齐随文档 JSON 保存，标准 Markdown 保留图片内容而不保留显示尺寸与对齐。
- 文档协作更新即时广播，数据库写入采用 500ms 防抖、最长 2 秒截止触发；合并增量后提交，持久化确认覆盖本端更新才显示已保存。手动保存、版本操作和停服前立即保存待处理更新；数据库失败保留未确认增量并自动重试，客户端继续保留恢复草稿。刷新读取服务端内容。Markdown 导入为可编辑正文并支持导出。文件体积上限 200 MB，转换后的文档内容仍受规模限制，本地图片上限 1MB。
- 顶部与浮动工具栏支持文字颜色、文字背景色和字号；紧凑选色面板包含预设色、两类自定义选色（字体色和背景色各只保留最后一个自定义颜色），支持恢复默认；包含字体颜色、背景颜色或字号时，导出 Markdown 会提示样式丢失，确认后导出标准 Markdown，原文档不受影响。
- 空间新建菜单通过统一「上传文件」入口也支持 Excel（`.xlsx`，200 MiB）和 Markdown（`.md` / `.markdown`，200 MiB），分别导入为可编辑表格与文档，并自动识别 PPTX（200 MiB）、PDF（200 MiB）、PNG/JPEG/WebP/GIF 图片（200 MiB）和 MP4/WebM 视频（200 MiB），上传成功即可预览及下载原文件。PDF 使用浏览器内置阅读器，图片支持缩放及全屏，视频使用原生播放控件并支持分段读取；播放兼容性取决于浏览器和编码。移动端使用紧凑顶栏，文件和分享权限沿用现有机制，原文件仍存私有附件目录。文档内插图继续限制为 1 MiB。
- 幻灯片仅支持 `.pptx`（上限 200 MB），通过 `@aiden0z/pptx-renderer` 在浏览器直接解析；支持上传 / 替换、缩略图跳转、翻页、左右方向键、50%–200% 缩放、全屏和原文件下载。原文件存入服务器私有附件目录，成员鉴权读取；替换保留历史引用，不依赖当前浏览器缓存。复杂版式与字体还原取决于渲染库，不提供编辑和动画播放。
- 表格使用 FortuneSheet 1.0.4，采用开始 / 插入 / 公式 / 数据 / 视图五个 Tab；支持编辑、公式、多工作表、格式设置、行列操作、筛选、排序、数据验证与撤销 / 重做；正式编辑通过服务端权威引擎协作并持久化至 PostgreSQL，支持在线选区、个人撤销与版本历史；未确认操作另存本机恢复副本。旧坐标修订窗口默认256；个人撤销保留最近256次本人操作且不超过4096个全局修订，超窗旧结构冻结进检查点，过期操作提示重新载入并保留恢复副本。
- ExcelJS 负责 `.xlsx` 导入导出，支持数据、公式、常用字体与颜色、背景色、数字格式、边框、合并单元格、冻结行列和尺寸及筛选范围；筛选条件、数据验证规则暂不进行 Excel 转换，本地保存会保留。不保证复杂 Excel 完整还原，图表、透视表、宏等高级对象暂不转换。导入文件体积限制 200 MB、20 万个非空单元格，单表最多 1 万行 / 1 千列。空间首页导入可创建表格，表格页导入会替换当前内容。
- 公开 / 私有分享使用真实访客只读入口，支持密码、有效期、撤销和重新签发；访客附件授权限于当前分享内容。
- 空间成员管理、六项独立密钥权限、权限预设、API Key 创建 / 查看 / 修改 / 删除与 MCP / HTTP 模板；列表不返回完整密钥，创建者可单独查看加密存储的原文，内容写入共用协作引擎。
- 浅色 / 深色主题通过共用主题弹窗设置，顶部图标、账号菜单和空间设置页共用入口；文档保存状态显示为顶栏图标，悬停查看状态，连接异常可点击重连。账号使用真实 Cookie 登录。

旧版演示数据仍保留在 localStorage 的 `minmd-static-demo-v1` 和 IndexedDB，登录不会自动导入。当前业务状态从服务器读取；设备主题和侧栏偏好仍保存在本机。旧数据可主动选择“导入旧演示”迁入当前空间；缺失附件显示失败并支持补文件重试，导入不会删除原数据。

## 分享与文件权限

新文档、表格和幻灯片默认私有，空间成员默认只读；创建者和空间负责人管理文件与分享。管理员可把空间成员默认权限改为可编辑，或为指定账号设置只读 / 编辑权限。指定账号可以不属于空间，其授权仅覆盖单个文件，不获得空间目录、其他文件或子文档权限。升级前的旧文件保留空间成员可编辑行为。

公开链接分为“登录用户可访问”和“所有人可查看”。链接可为登录用户授予只读或编辑权限；未登录访客始终只读。公开授权与独立授权取较高权限，因此公开可编辑时不能用指定只读降低该公开权限。分享密码、有效期、撤销和重置链接仍生效；内部成员及指定协作者使用独立授权访问，不受公开链接密码和有效期影响。

已登录用户无权访问时可以申请访问，已有只读权限时可以申请编辑。同一文件、同一用户只保留一个待处理申请，申请人可取消；创建者或空间负责人在分享弹窗批准只读、批准编辑或拒绝，结果写入站内通知。右上角账号菜单提供“分享给我的”和“站内通知”，头像显示未读数量。授权变更重新校验文档和表格在线编辑会话，失去编辑权限的会话立即断开；只读页面和匿名访客不占编辑会话名额。正文、附件、版本与 AI 写入使用同一套文件权限判断。

## 主题与工程

`apps/web/src/theme.less` 集中定义语义颜色、文件类型颜色、字体、间距、尺寸、圆角与动效变量。`data-theme` 切换浅色 / 深色，Ant Design 配置同步读取颜色变量。样例纸张使用单独的预览色变量。

React 18、TypeScript、Vite、Hash Router、Zustand、Ant Design、Tiptap、lucide-react、Less Modules。跨模块引用使用 `@/`，页面与组件采用目录式组织。

后台账号与系统权限沿用脚手架自带管理界面，MinMD 空间元数据和成员管理已接入。后台空间管理不授予私有文档正文读取权限。

正式协作每文件默认允许 10 个编辑会话，同账号多页面分别计数。文档与表格连接入口默认每秒最多 100 条消息，可分别配置 1–1000；超限关闭连接，未确认操作保留恢复副本。表格消息和当前投影默认各最多 8 MiB，可配置 1 KiB–8 MiB；最多 30 个工作表，单表最多 10,000 行、1,000 列，同时受单表 300,000 个网格位置上限约束。XLSX 的 200 MB 文件体积限制不替代转换后工作簿的这些限制。文档权威状态与 JSON 投影各限制 8 MiB。

性能基线使用 Apple M4、10 核、16 GiB、Bun 1.3.13 和本机 PostgreSQL，均为 10 个真实账号会话。125,890 字符文档的持久确认 P95 为 291ms；10,000 个非空单元格、1,000 个公式及并发行操作表格的 P95 为 2,772ms。两者均验证数据库收敛和进程重启恢复；这些是该规模的本机协议及数据库结果，不包含浏览器渲染或广域网延迟，也不代表无限并发。

可在独立 `_test` 数据库复验，脚本会创建并清理本次测试数据：

```sh
TEST_DATABASE_URL=postgresql://user:password@127.0.0.1:5432/minmd_test bun scripts/benchmark-document-collaboration.ts
TEST_DATABASE_URL=postgresql://user:password@127.0.0.1:5432/minmd_test bun scripts/benchmark-sheet-collaboration.ts
```

## 表格协作开发验证

设置 `SHEET_COLLAB_VERIFY_ENABLED=true` 后启动开发环境，在表格顶部点击「协作验证」。前台通过开发配置 `API_PROXY_TARGET` 对应的 WebSocket 地址连接后端。两个页面打开同一文件 ID 即进入同一房间，使用演示身份，不能代替账号或空间权限验证；正式 / 预发环境禁止开启此模块，生产前台不显示入口。

每份表格默认最多 **10 个编辑会话**，同一账号打开两个页面占两个名额。`SHEET_COLLAB_MAX_SESSIONS` 可设置 1–100，第 11 个会话被拒绝，连接关闭后释放名额。验证数据在 `SHEET_COLLAB_VERIFY_DIR`（默认 `runtime/sheet-verification`）落盘，此目录已忽略。

服务端串行提交并在落盘后广播，普通单元格冲突按服务端接收顺序处理；结构变动后的旧修订操作被拒绝。断开 / 冲突时未确认内容保留为本地恢复副本，页面可下载 XLSX，再手动重连加载权威状态。这不是完整 OT 引擎：复杂行列并发、引用重定位、个人撤销、自动重连、鉴权和正式存储仍需完善，不能据此声明阶段 1 全部完成。

旧 Univer 本地快照读取时转换为 FortuneSheet；`@univerjs/core` 仅保留旧格式转换需要的类型和枚举，不再运行旧表格编辑器。ExcelJS 保留基础 XLSX 导入导出。

## 文档协作开发验证

设置 `DOC_COLLAB_VERIFY_ENABLED=true` 后启动开发环境，在文档顶部点击「协作验证」。同一文档 ID 的页面使用 Tiptap Collaboration + Yjs + Hocuspocus 4.7.0 同步正文，显示在线光标与选区，支持个人撤销和自动重连。初始化由服务端指定单个页面导入本地正文，其他页面读取权威内容，避免重复导入；验证模式下标题只读，文件名称与空间元数据暂不参与协作。

每份文档默认最多 **10 个编辑会话**，`DOC_COLLAB_MAX_SESSIONS` 可配置 1–100。同账号多页面分别占名额，第 11 个会话拒绝；连接关闭释放名额。文档与表格的会话上限分别配置。服务端通过 Hocuspocus 接收 Yjs 更新，将二进制状态原子替换写入 `DOC_COLLAB_VERIFY_DIR`（默认 `runtime/document-verification`，已忽略）。客户端核对持久化确认的 Yjs 状态快照（包含删除信息）后才显示「已保存到服务器」。

断线时暂停编辑并自动重连，当前页面保留未同步更新；不要在未确认保存时关闭 / 刷新页面。浏览器刷新后重新点击验证入口读取服务器状态，页面丢失前的未落盘输入不保证恢复。服务退出会等待验证状态写入。协议测试包含同位置并发收敛、个人撤销、隔离房间、重连、服务端直接写入广播、重启恢复、10 会话限制及名额释放；浏览器验证正文双向同步与个人撤销。

此入口仅限本机 development，采用演示身份，默认关闭，预发 / 正式环境拒绝开启，生产前台不显示按钮。它尚未接入真实账号、空间权限、附件授权、版本历史及 schema / epoch 管理，不代表正式业务协作已完成。

API 密钥的认证使用哈希，完整值采用 AES-256-GCM 加密保存。`AI_KEY_ENCRYPTION_KEY` 需配置为 64 位十六进制，未配置时仅影响新密钥创建及原文查看；已有密钥仍能认证。部署、备份恢复须保留此配置，更换后旧密钥原文无法解密。创建者可查看自己的完整密钥，空间负责人可管理空间全部密钥但不能读取他人原文。删除会移除密钥及其幂等记录，保留不含秘密的操作审计。迁移会将旧策略和密钥权限的交集写入密钥，原本关闭的密钥保持失效；旧密钥仅存哈希，无法补回完整值。

文档、表格和 PPT 每个文件最多保留最近 100 个历史版本，所有来源统一计数。生成新版本时在同一事务内清理超额版本，服务启动时也会清理已有超额版本。当前内容独立保存；清理只释放被删除版本的附件引用，仍被当前内容或其他版本引用的附件不会删除，失去全部引用的附件沿用现有宽限期清理。
